# Task 2 — PageRank 수렴 실험

## 사전 예상과 방법

beta가 커지면 수렴이 느려질 것으로 예상했다. 노드·간선이 늘면 한 반복의 시간이 늘겠지만 반복 횟수가 노드 수에 비례하지는 않을 것으로 예상했다. 허용 오차가 작아지면 더 많은 반복이 필요할 것으로 예상했다.

CPU 11th Gen Intel(R) Core(TM) i5-11400H @ 2.70GHz, RAM 15.74 GiB, Windows-10-10.0.26200-SP0, Python 3.11.9에서 실행했다. Codex가 실행 중이었고 다른 앱 부하는 통제하지 않았다. 제공 bench.build(seed=246)를 사용했으며 bench.py는 수정하지 않았다. 모든 노드는 1/n으로 시작한다. 시간에는 PageRank 호출을 포함하며 그래프 생성·순위 정렬·파일 저장은 제외한다. tracemalloc은 사용하지 않았다.

1200개 그래프(beta=0.85)의 시험 실행 한 건은 pilot로 따로 보존하고 집계에서 제외했다. 본 실험은 조건당 3회이며 beta 순서를 두 번째 반복에서 뒤집었다. 크기별 실험은 따로 실행했으므로 실행 순서와 배경 부하가 시간에 영향을 줄 수 있다. 표의 시간은 중앙값(최솟값–최댓값), 단위는 초이며 신뢰구간이 아니다.

## beta와 반복 횟수 (A1–A3)

1,200개 노드, 5,877개 간선, tol=1e-10, 최대 500회이다.

| beta | 반복 횟수 | 시간 중앙값(범위), s | 최종 L1 변화량 |
|---:|---:|---:|---:|
| 0.5 | 14 | 0.01376 (0.01040–0.01770) | 2.28e-11 |
| 0.7 | 17 | 0.01680 (0.01525–0.01727) | 5.32e-11 |
| 0.85 | 20 | 0.02187 (0.01471–0.02827) | 7.37e-11 |
| 0.95 | 23 | 0.02565 (0.02153–0.02636) | 4.74e-11 |
| 0.99 | 24 | 0.03090 (0.01887–0.03530) | 5.24e-11 |

반복 횟수는 14→17→20→23→24회로 늘었다. beta가 커지면 순간 이동의 비중이 작아지고 링크 구조의 영향이 오래 남는다. 확률을 보존하는 전이에서 PageRank 갱신의 L1 차이는 최대 beta배로 수축하므로 beta가 1에 가까울수록 최악의 수축 보장이 약해진다. 실제 속도는 그래프 구조·초기값에도 좌우된다. 이 그래프에서는 beta=0.99도 24회에 수렴했으므로 1 근처에서 반드시 급격히 느려진다고 쓰지는 않는다. 짧은 시간 측정에서는 실행 시간이 반복 횟수 순서와 정확히 일치하지 않을 수 있다.

## 그래프 크기 비교 (A4)

노드 수 1,200→6,000으로 5배, 간선 수 5,877→30,433으로 약 5.18배이다. 두 크기 모두 tol=1e-10이다.

| beta | 반복 수 작은/큰 | 작은 그래프 시간(s) | 큰 그래프 시간(s) | 시간 배율 | 반복당 중앙 시간 작은/큰(ms) |
|---:|---:|---:|---:|---:|---:|
| 0.5 | 14 / 14 | 0.01376 (0.01040–0.01770) | 0.07747 (0.05938–0.09046) | 5.63 | 0.983 / 5.534 |
| 0.7 | 17 / 18 | 0.01680 (0.01525–0.01727) | 0.12153 (0.09363–0.13320) | 7.23 | 0.988 / 6.752 |
| 0.85 | 20 / 22 | 0.02187 (0.01471–0.02827) | 0.13403 (0.12202–0.19521) | 6.13 | 1.093 / 6.092 |
| 0.95 | 23 / 24 | 0.02565 (0.02153–0.02636) | 0.14479 (0.11664–0.21116) | 5.65 | 1.115 / 6.033 |
| 0.99 | 24 / 25 | 0.03090 (0.01887–0.03530) | 0.18086 (0.15588–0.19508) | 5.85 | 1.288 / 7.234 |

반복 횟수는 같거나 1–2회만 늘었지만 시간은 더 크게 늘었다. 각 반복은 노드와 간선을 순회하므로 한 번의 계산량이 증가한다. 수렴 횟수는 같은 계산을 몇 번 해야 하는가라는 별개의 문제다. 크기별로 같은 생성 방식과 시드를 사용했지만 같은 그래프를 단순 확대한 것은 아니다. dead end 선택과 링크 구조도 달라지므로 반복 횟수 차이를 크기만의 인과 효과로 단정하지 않는다.

## 허용 오차 비교 (A5)

1,200개 노드, beta=0.85를 고정했다. 허용 오차 범위는 1e-3부터 1e-7까지 10,000배이다.

| tol | 반복 수 | 이전 조건보다 추가 반복 | 시간 중앙값(범위), s | 최종 L1 변화량 |
|---:|---:|---:|---:|---:|
| 1e-03 | 7 | — | 0.00633 (0.00502–0.00652) | 0.00052 |
| 1e-04 | 9 | 2 | 0.00894 (0.00840–0.00973) | 3.03e-05 |
| 1e-05 | 10 | 1 | 0.00761 (0.00756–0.01300) | 6.27e-06 |
| 1e-06 | 12 | 2 | 0.01049 (0.00950–0.01124) | 4.54e-07 |
| 1e-07 | 14 | 2 | 0.01431 (0.01051–0.01762) | 3.84e-08 |

한 자리 엄격하게 할 때 추가 반복은 2·1·2·2회였다. 네 자리 동안 총 7회, 평균 1.75회/자리였다. 실제 증가량은 정수로 계단처럼 변하며 다른 beta나 그래프에 동일하게 적용되는 상수가 아니다. L1 변화량은 연속한 두 벡터의 차이이며 참 정상분포와의 직접 오차가 아니다.

## 상위 10위 변화 (A6)

아래는 1,200개 그래프이며 6,000개 그래프에서도 같은 순서 변화가 관찰됐다. 같은 조건의 세 반복에서 순위는 동일했다. 동점일 경우 노드 이름으로 정렬한다.

| beta | 순위 1→10 |
|---:|---|
| 0.5 | p00009 → p00001 → p00006 → p00005 → p00003 → p00002 → p00000 → p00004 → p00007 → p00008 |
| 0.7 | p00009 → p00001 → p00006 → p00005 → p00003 → p00002 → p00004 → p00000 → p00007 → p00008 |
| 0.85 | p00009 → p00001 → p00006 → p00005 → p00003 → p00002 → p00004 → p00000 → p00007 → p00008 |
| 0.95 | p00009 → p00001 → p00006 → p00005 → p00003 → p00002 → p00004 → p00000 → p00007 → p00008 |
| 0.99 | p00009 → p00001 → p00006 → p00005 → p00003 → p00002 → p00004 → p00000 → p00007 → p00008 |

상위 10개 구성은 모든 측정 beta에서 동일했다. 순서는 beta=0.5에서 p00000이 7위, p00004가 8위였으나 beta=0.7에서 뒤집혔다. 측정한 beta 중 최초 변화는 0.7이며, 0.5와 0.7 사이의 정확한 교차점을 측정한 것은 아니다.

1,200개 그래프의 beta=0.5에서는 두 점수가 각각 0.027823245와 0.027216943(차이 약 0.000606302), beta=0.7에서는 0.038244535와 0.042115585(차이 약 0.003871050)였다. 이 차이는 종료 기준보다 충분히 크다. L1 수축에 따른 사후 오차 상계 beta*delta/(1-beta)도 두 조건에서 각각 약 2.28e-11, 1.24e-10이므로 이번 순서 변화는 종료 오차로 설명되지 않는다. 원시 파일에 상위 10개 점수를 모두 보존했다.

따라서 상위 집단의 안정성과 세부 순위의 안정성은 다르다. 공개 순위를 해석할 때 beta와 계산 조건을 확인해야 하며, beta=0.85가 모든 목적에 유일하게 옳은 값은 아니다.

## 수렴 확인과 재현

본 실험 45건 모두 delta < tol을 만족했고 합계는 부동소수점 오차 범위에서 1이었다. 500회 상한에 도달한 미수렴 결과는 없었다. JSON에는 converged, delta, max_iter, 실제 반복 수와 각 실행 환경을 기록했다.

```bash
python task2_convergence.py --label beta
python task2_convergence.py --nodes 6000 --label size
python task2_convergence.py --betas 0.85 --tol 1e-3 --label tolerance
python task2_convergence.py --betas 0.85 --tol 1e-4 --label tolerance
python task2_convergence.py --betas 0.85 --tol 1e-5 --label tolerance

python test_tasks.py --task 2
```
