# Task 3 — 같은 군집을 더 적은 거리 계산으로 구하기

## 예상과 구현

초기 중심을 동일하게 주고 기준 NaiveKMeans의 배정 순서와 `d < best - 1e-12` 비교를 유지했다. 군집 갱신에는 원본 _means를 재사용해 빈 군집의 이전 중심 유지와 덧셈 순서도 맞췄다. Task 1의 빈 군집 이동 정책과 Task 3의 기준 구현 정책은 서로 다르다.

점마다 자신의 중심까지 거리의 상한 u와 다른 모든 중심까지 거리의 하한 l을 저장한다. 중심이 움직인 거리 m을 구한 뒤 u에는 자신의 중심 이동량을 더하고 l에서는 전체 중심의 최대 이동량을 뺀다. 삼각부등식에 의해 안전하지만 느슨할 수 있는 경계다.

또한 각 중심에서 다른 중심까지 최소 거리의 절반 s를 구한다. `u < l`이면 다른 중심이 더 가까울 수 없으며 `u < s`이면 중심 사이의 간격으로 같은 결론을 얻는다. 이 구현은 1e-12 비교와 반올림을 고려한 보수적인 여유 `(k+2)*1e-12 + 1e-10*max(1,u)`를 더해 엄격하게 통과할 때만 생략한다. 경계에서 애매하면 실제 거리를 다시 계산한다.

첫 검사에서 실패하면 자신의 중심까지 실제 거리를 계산해 u를 좁힌 뒤 다시 검사한다. 또 실패하면 모든 중심을 기준과 같은 순서로 비교한다. 이미 계산한 자신의 거리는 재사용한다. 첫 반복에는 이전 배정이 없으므로 모든 점과 모든 중심의 거리가 필요하다.

거리 호출은 88.85% 감소했다. SSE 차이는 0이고 배정 번호와 중심 좌표도 정확히 일치했다. 동일한 초기 중심·배정 판단·평균 갱신을 수행하며 군집을 바꿀 수 없다고 판단된 비교만 생략한 결과다. 공식 허용치인 SSE 0.1% 이내보다 강한 비교를 추가했다. 다른 입력에 대한 보장은 아래 사례 검증과 수학적 경계의 전제 범위에서 해석해야 한다.

저장된 시간 값은 실행 과정에서 별도의 검증 작업과 일부 겹쳤으므로 속도 향상의 근거로 사용하지 않는다. 이번 과제의 평가지표는 거리 호출 수이며 호출 감소를 시간 감소와 동일시하지 않는다. CPU·플랫폼·RAM은 원자료에 기록했다.

## 어떤 경계가 일을 했는가? (R5)

한 번의 배정 검사에서 두 경계를 모두 검사하되, 통과 횟수는 하한 경계를 먼저 귀속했다. 이 순서는 실제 기여를 분리하는 제거 실험이 아니며 두 경계의 효과가 겹친다.

- 하한 l 검사에 먼저 귀속된 점 검사: 549,881회.
- l은 통과하지 못하고 중심 간격 s만 통과한 점 검사: 218,137회.
- 두 경계 모두 통과한 점 검사: 68,420회 (위 귀속 수와 겹침).
- 자신의 거리로 상한을 좁힌 다음에 통과한 점 검사: 43,926회 (위 수와 겹침).
- 전체 중심 비교가 필요했던 점 검사: 91,982회.

이 기록을 통해 어느 검사가 생략에 주로 사용됐는지 확인할 수 있다. 중복된 수를 더해 생략률로 계산하지 않는다. 특정 경계를 제거했을 때 전체 계산이 얼마나 늘어나는지는 별도로 측정하지 않았다.

## 유지 비용과 저장 공간

실제 거리 호출은 점–중심 1,147,710회, 중심 이동 504회, 중심 간격 2,772회다. 중심 간 거리도 모두 전달받은 distance를 호출해 공식 카운터에 포함한다. 경계 유지를 위해 숨겨서 거리를 계산하지 않는다.

점당 배정 번호 외에 상한·하한 실수 2개를 추가하므로 경계 벡터는 2n개, 공식 n에서는 40,000개 수다. 중심별 간격 k개, 이동량 k개, 전체 비교 때 임시 거리 k개, 중심 좌표 O(kd), 반복별 통계도 필요하다. 이는 Python 전체 바이트 메모리 계측이 아니다. 모든 점–중심 하한을 저장하는 O(nk) 표는 만들지 않는다.

경계 갱신은 반복마다 O(n), 중심 간격은 O(k²d), 중심 이동은 O(kd)다. 군집 평균 갱신은 원본처럼 군집별 점 목록을 만들며 별도의 비용이 있다. 경계가 느슨하거나 군집이 겹치면 계산 생략 이점이 작아져 유지 비용이 더 클 수 있다.

첫 반복은 거리 호출 240,078회이며 전체의 20.86%다. 점–중심 nk=240,000회에 다음 반복을 위한 중심 이동·간격 초기 설정이 포함된다. 따라서 순수 첫 배정과 설정까지 포함한 첫 반복을 구분한다.
