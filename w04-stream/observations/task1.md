# Task 1 — Observation

## Bloom filter

삽입 시 설정한 비트를 지우지 않고 조회 시 같은 해시 위치를 검사하므로, 동일한 값 표현과 변경되지 않은 필터 설정에서는 삽입한 항목에 대한 미탐이 발생하지 않는다. 문자열 입력을 대상으로 검증했다. 전체 입력을 저장하지 않고 비트를 bytearray에 압축해 저장한다.

8,192비트, 해시 5개, 삽입 항목 800개에서 이론 오탐률 `(1 - exp(-kn/m))^k`는 약 0.860%, 삽입하지 않은 20,000개에 대한 실측 오탐률은 0.835%(167개)였다. 삽입한 800개에 대한 미탐은 0개였다. 이론식은 균등하고 독립적인 해시를 가정한 근사이며, 유한한 조회 표본에서도 실측값이 달라질 수 있다. 검증 통과만으로 모든 입력의 오탐률이 이론값과 일치한다고 보장하지는 않는다.

## Flajolet–Martin

64개 해시 출력 각각의 최대 후행 0 개수를 보관한다. SHAKE-256 출력의 서로 다른 64비트 구간을 해시 출력으로 사용하며, 입력은 한 번만 순회한다. 각 최대값 R의 추정값은 2^R이다. 기본 설정에서는 8개씩 묶어 중앙값을 구한 뒤 8개 그룹 중앙값을 평균한다. 입력 크기와 무관하게 고정 개수의 해시 상태를 보관한다.

제공 검증 데이터의 실제 고유 항목 수는 19,953개였다. 동일한 해시 결과에 세 결합 방식을 적용했다.

| 결합 방식 | 추정값 | 실제값 대비 비율 |
|---|---:|---:|
| 단순 평균 | 65,344 | 3.27배 |
| 전체 중앙값 | 16,384 | 0.82배 |
| 그룹별 중앙값의 평균 — 선택 | 24,576 | 1.23배 |

단순 평균은 큰 2^R 값의 영향을 크게 받았다. 중앙값은 이상값의 영향을 줄이지만 값이 거칠게 변한다. 짝수 개 표본의 중앙값은 가운데 두 값의 평균이므로 반드시 2의 거듭제곱인 것은 아니다. 선택한 방식은 그룹 안에서 이상값 영향을 줄이고 그룹 간 평균으로 값을 결합한다. 전체 중앙값보다 항상 정확하다는 주장은 아니다.

추가로 고유 항목 수 100·2,000·20,000과 해시 시드 246부터 250까지의 15개 조합을 확인했다. 입력은 `k0`부터 시작하는 서로 다른 문자열이며, 같은 최대값 배열로 결합 방식만 비교했다.

| 결합 방식 | 추정값/실제값 최솟값–최댓값 | 0.5배에서 2배 이내 |
|---|---:|---:|
| 단순 평균 | 2.092–211.571 | 0/15 |
| 전체 중앙값 | 0.819–1.638 | 15/15 |
| 그룹별 중앙값의 평균 | 0.992–1.680 | 15/15 |

이 결과는 선택한 데이터와 시드의 확인 결과이며 모든 스트림에서 오차가 2배 이내라는 보장은 아니다. 빈 입력은 0을 반환하며, 같은 항목을 반복해도 최대값은 달라지지 않는다.

## Reservoir sampling

첫 k개를 저장하고, 이후 t번째 항목마다 `rng.randrange(t)`로 0부터 t-1까지 균등하게 뽑는다. 결과가 k보다 작을 때 해당 슬롯을 교체하므로 새 항목의 선택 확률은 k/t이다. 기존 항목의 잔류 확률도 귀납적으로 k/t가 되며, 스트림의 최종 길이를 미리 알 필요가 없다. 표본으로 저장하는 항목은 최대 k개이다. 균등성은 서로 다른 값의 종류가 아니라 입력의 각 위치에 대한 것이다.

제공 검증의 20개 항목 중 5개를 뽑는 실험을 4,000회 실행했다. 항목당 기대 선택 횟수는 1,000회였고 `(최대 횟수 - 최소 횟수) / 기대 횟수`는 8.9%로 기준 15% 미만을 통과했다. 이는 반복 실험 결과이며, 균등성의 근거는 위의 선택·잔류 확률이다. k=0, 입력 길이가 k보다 짧은 경우도 확인했다.
